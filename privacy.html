プライバシーポリシー

アプリ名：音描（DotMusic）／提供：みつぼし／最終更新日：2026年11月12日

みつぼし（以下「私たち」）は、アプリ「音描」（以下「本アプリ」）における、利用者のプライバシーを大切にしています。

収集する情報

本アプリは、氏名、メールアドレス、位置情報などの個人情報を一切収集しません。アカウント登録も必要ありません。

作品データとQRコードについて

利用者が作った絵や曲のデータは、利用者の端末内で扱われます。QRコードは端末上で作られ、作品のデータはQRコード自体に含まれます。本アプリが、作品データを私たちのサーバーへ送信・保存することはありません。

QRコードを読み取ると、ブラウザで GitHub Pages 上のページが開き、QRコードに含まれる作品データをもとに曲が再生されます。このとき、ページの配信元である GitHub が、アクセスの記録（IPアドレスなど）を取得する場合があります。その扱いは GitHub のプライバシーに関する声明 に従います。GitHub が取得する記録を、私たちが個別に取得・利用することはありません。

再生ページでは、利用状況を知るために、アクセス解析サービス「GoatCounter」でアクセス数を数えています。GoatCounter は、Cookie を使わず、個人を特定する識別子での追跡や個人情報の継続的な保存を行わない仕組みです。取得するのは、閲覧されたページ、ブラウザの種類、おおよその地域、画面サイズ、アクセス元のサイトなどの統計情報です。詳しくは GoatCounter のプライバシーポリシー をご覧ください。これらの情報は、個人を特定する目的では使わず、第三者への提供もしません。

再生ページは、文字を表示するために、Google が提供する「Google Fonts」からフォントを読み込みます。このとき、Google にアクセス元の情報（IPアドレスなど）が送られる場合があります。取り扱いは Google のプライバシーポリシー に従います。

第三者への提供・広告・解析

本アプリ自体には、広告や利用状況の解析ツールは入っていません。収集した情報を第三者に提供することもありません。

お子さまの利用について

本アプリは個人情報を収集しないため、お子さまも安心して利用できます。
